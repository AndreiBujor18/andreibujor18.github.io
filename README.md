# Andrei Bujor - Personal portfolio

Site personal bilingv (RO/EN), responsive și construit fără framework-uri.

Direcția vizuală combină un stil editorial cu un traseu care se transformă
în circuit, inspirat de proiectele Campus USV și Calculator Binar Verilog.
Tipografia folosește familiile Source Serif 4 și IBM Plex, încărcate prin
Google Fonts.

Site public: [andreibujor.ro](https://andreibujor.ro/)

## Rulare locală

Deschide `index.html` direct sau pornește un server local din director:

```bash
python -m http.server 8080
```

Apoi accesează `http://localhost:8080`.

## Publicare cu GitHub Pages

Repository-ul este pregătit pentru publicare ca site GitHub Pages la adresa
`andreibujor18.github.io`, cu domeniul personalizat `andreibujor.ro`.

Fișierul `CNAME` păstrează asocierea domeniului, iar `.nojekyll` indică GitHub
Pages să livreze fișierele statice fără procesare Jekyll.
